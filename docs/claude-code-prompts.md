# ねかせ — Claude Code への依頼文集

VS Code の Claude Code に、順番に貼って使う。1つ終わったら、動作を確認してから次へ進む。

## 使い方

1. リポジトリの直下に、次の3つを置く。
   - `CLAUDE.md`(自動で読まれる)
   - `docs/nekase-plan.md`(計画書)
   - `docs/prototype/nekase.html`(プロトタイプ。見本)
   - `docs/claude-code-prompts.md`(このファイル)
   - AWS編を使うときは、`infra/aws` を作る(AWS-1 の依頼文で作られる)
2. VS Code でリポジトリを開き、Claude Code を起動する。
3. 下の依頼文を、上から順にコピーして貼る。`【担当】` は、そのステップをやる人。
4. 1ステップごとに、ブランチを切って Pull Request にする。
5. うまくいかないときは、**エラーの全文**をそのまま貼って、「原因と直し方を平易に説明して」と頼む。

> 迷ったときの合言葉: 「変更する前に、やることを3行で説明して。私が OK と言ってから実装して」

### AWS-4: 監視と運営ダッシュボード【担当C+B】

```
監視と、運営ダッシュボードを作ってください。

CDK 側(C):
- CloudWatch のアラーム: 受け口の Lambda のエラー、集計の Lambda の失敗。通知先は、チームのメールだけ(アプリの利用者には送らない)
- ログの保持期間を決める(長すぎない)

アプリ側(B):
- Web版の /ops ページ。キーを入力すると、GET /v1/summary の結果を、週ごとの表と簡単なグラフで表示する(読み取り専用)
- キーは、保存しない(画面を閉じたら消える)
- ページの冒頭に、「匿名の回数だけを集計しています。睡眠の時刻や取引の内容は含みません」と書く
- 利用者向けの画面からは、リンクを張らない
```

### AWS-5: アプリからの送信とオプトアウト【担当A(またはC)】

```
アプリ(apps/mobile)から、匿名イベントを送る処理を作ってください。

- イベントの種類は、許可リストの6つだけ。型で表現し、それ以外を送れないようにする
- 送る項目は、eventId(乱数)、type、platform、appVersion のみ。アカウント ID、端末の識別子、睡眠の時刻、取引の内容を、一切含めない
- 設定に「利用状況の送信」のオン・オフを置く。初回に、何を送るかを平易に説明する。オフなら、送信しない
- 送信は、失敗しても画面に出さず、アプリを止めない。再試行は少なく(最大2回)
- 送信のコードは、本体のロジックと切り離す(本体のテストが、AWS なしで通る)

テスト: オフのときに送られないこと、送る項目が許可した範囲だけであること、通信失敗でアプリが落ちないことを確認してください。
```

### AWS-6: 発表の準備【担当C+A】

```
AWS の学習モジュールの発表資料を作る手伝いをしてください。
1. 構成図(アプリ → API Gateway → Lambda → DynamoDB、EventBridge Scheduler → 集計 Lambda、CloudWatch、Budgets)を、Mermaid で書いてください。
2. 「なぜ本体は Cloudflare、周辺は AWS に分けたか」を、3つの理由で説明してください(データの正を1か所にする、止まっても本体が動く、送るデータを最小にできる)。
3. 学んだこと(サービスごとに1行)と、うまくいかなかったことを、正直に書く欄を作ってください。
4. 発表の当日に AWS が使えない場合の、代わりの見せ方(構成図とスクリーンショット)を提案してください。
```
